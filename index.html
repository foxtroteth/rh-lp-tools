RH LP Tools

Scriptable scripts for Uniswap V4 liquidity on Robinhood Chain. Find USDG pools, open single-sided ladders, and claim, close or re-enter them from your iPhone.

Service fee

These scripts are free to download. Using them to transact charges a fee:

Open a positionRH Pool zap, or re-entry / roll in RH Portfolio0.3 USDG per open
Claim fees or closeRH Portfolio1.5% of the LP fees collected
Everything elseviewing, swaps, cleanup, practice modeFree
  • The 1.5% is of the LP fees you earned, never of your deposit. Fees earned in the other token are valued at the pool's live price and the cut is paid in USDG.
  • It is paid inside the same transaction as the action. If the action fails, no fee is paid.
  • If a claim or close returns too little USDG to cover the cut, the rest comes from USDG in your wallet. If there is none, the same 1.5% is taken from each fee token instead, so a fee can never stop you exiting.
  • Every confirmation screen shows the fee before you send, and the exact amount appears as its own step.

Setting up

About 10 minutes. You need iOS 14 or newer, a little ETH on Robinhood Chain for gas, and USDG to deposit.

1. Install Scriptable

Get Scriptable by Simon Støvring from the App Store. It is free, and it is what runs these scripts on your phone.

2. Create RH Secrets

  1. Open this page in Safari on the same phone. Under Download, tap Copy code next to RH Secrets.
  2. Open Scriptable and tap + (top right). A blank script opens.
  3. Long-press in the editor and tap Paste.
  4. Tap the title at the top of the editor and rename it to exactly RH Secrets, with the space and capitals. The other two scripts find it by that name.
  5. Fill in your keys between the quotes (see Getting your keys). Leave PRACTICE_MODE: true.
  6. Tap Done.

3. Create RH Pool and RH Portfolio

  1. Back on this page, tap Copy code next to RH Pool.
  2. In Scriptable, tap +, paste, rename it to exactly RH Pool, tap Done.
  3. Do the same for RH Portfolio.

These are large files. If the paste looks cut off, scroll to the bottom of the script: the last line should be Script.complete();. If not, copy and paste again.

4. Practice run

  1. Tap RH Pool in Scriptable's list to run it. The pool table loads (the first load can take a minute).
  2. Tap a zap button on any pool. It shows the plan, the gas and the 0.3 USDG service fee, and sends nothing.
  3. Run RH Portfolio the same way and try Claim and Close on a position if you have one.
  4. When the numbers look right, open RH Secrets, change PRACTICE_MODE: true to false, tap Done. From then on the buttons really send.

5. Home screen widget (optional)

  1. Long-press an empty spot on your home screen until the icons wiggle, then tap Edit or + (top left).
  2. Search Scriptable, choose the Medium or Large size, tap Add Widget.
  3. Long-press the new widget, tap Edit Widget, set Script to RH Pool or RH Portfolio, and set When Interacting to Run Script.
  4. Tap outside to finish. The widget refreshes on its own; tapping it opens the full table, where the buttons are.

Widgets only display. Opening, claiming and closing always happen in the full table, after a confirmation.

Updating

Tap Copy code for the script that changed, open it in Scriptable, select all (long-press, Select All), paste over it, tap Done. Never replace RH Secrets: your keys and presets live there.

If something goes wrong

  • "Set a wallet" or no buttons: RH Secrets is misnamed, or PRIVATE_KEY is empty or not 64 hex characters.
  • "ALCHEMY_API_KEY is required": the Alchemy key is missing, or you pasted the whole URL instead of just the key.
  • Balance shows but no positions: add a Blockscout key, then close and re-run the script.
  • Widget says it can't find a script: the widget's Script setting points at an old name. Pick it again.

Not available on Android yet

RH Pool and RH Portfolio run inside Scriptable, an app that exists only on iPhone and iPad. The scripts use Scriptable's own tables, dialogs, storage and widgets, so there is no Android app that can run them as they are.

Do not paste these scripts, or your private key, into an Android "JavaScript runner" or any other app that claims to run them. It will not work, and you would be handing that app the key to your wallet.

What you can do instead

  • Use an iPad or an old iPhone. Anything on iOS 14 or newer runs Scriptable. It does not need a SIM, just Wi-Fi. Follow the iPhone / iPad guide on that device.
  • Check back. An Android version is being considered. This page will have a guide here when it exists.

Your Android phone can still show this page and the fee terms. Only running the scripts needs iOS.

Getting your keys

Alchemy (required)

Sign up free at alchemy.com, create an app on Robinhood Chain, and copy the API key (the short string, not the URL) into ALCHEMY_API_KEY.

Wallet private key (required to transact)

Use a fresh wallet you keep only for this, holding only what you are willing to risk. The key stays on your phone: the scripts use it to sign locally and never send it anywhere. Anyone who can read the file can spend that wallet, so never share RH Secrets or paste the key anywhere else.

Blockscout (strongly recommended)

Free at blockscout.com. Without it, position lookups fall back to a public explorer that often times out: the symptom is a wallet that shows a balance but no positions.

Uniswap (only for swaps)

Free at hub.uniswap.org. Needed for "close and swap" and cleanup. Opening, claiming and closing work without it.

Questions

What does "single-sided ladder" mean?

You deposit only USDG, split across several slices placed below the current price. Nothing is bought up front, so there is no slippage on entry. The ladder earns fees only once the price falls into it, and as it does, your USDG is converted into the token.

How is the 1.5% worked out exactly?

Right before sending, RH Portfolio reads each position's uncollected fees from the chain, values any non-USDG part at the pool's current price, and takes 1.5% of the total, rounded up to the nearest 0.000001 USDG. That amount is paid to the fee wallet in the same transaction that collects the fees.

Does re-entering or rolling cost both fees?

Yes. A re-entry closes a ladder and opens a new one in one transaction, so it pays 1.5% of the fees collected plus 0.3 USDG for the re-open. A roll is the same, in separate steps.

Positions don't show up

Add a Blockscout key. The public explorer is slow and unreliable; with a key, lookups are fast. Newly opened positions can also take a minute to be indexed.

How do I update?

Copy the new code for RH Pool or RH Portfolio and paste it over the old script. RH Secrets is never replaced, so your keys and presets carry over.

Risks

  • Providing liquidity can lose money. If the price falls through your ladder, you end up holding the token at a lower value than the USDG you put in.
  • Many tokens on this chain are new, thin and volatile. Check a pool's TVL before depositing.
