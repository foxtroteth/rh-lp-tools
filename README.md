# rh-lp-tools

Public download page for the fee-charging builds of Robinhood Pool, Robinhood
Portfolio and the Robinhood Secrets template, for iPhone (Scriptable) and
Android (HTTP Shortcuts). Static: `index.html`, `scripts/` and `android/`.

The scripts are generated, not edited here. Rebuild them from the apex-hood
repository with `node tools/build-scripts.mjs`, then copy `build/public/*.js`
into `scripts/`.
